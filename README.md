<h2>LumaDent Studio</h2>

<p>
  A modern dental clinic website built with Next.js, React and TypeScript, focused on responsive design, interactive user experiences and appointment booking.
</p>

<h2>Tech Stack</h2>

<ul>
  <li>Next.js (App Router).</li>
  <li>React.</li>
  <li>TypeScript.</li>
  <li>CSS.</li>
  <li>Bootstrap.</li>
  <li>Figma.</li>
  <li>Visual Studio Code.</li>
</ul>

<h2>Features</h2>

<ul>
  <li>Built with the Next.js App Router using reusable React components and TypeScript.</li>
  <li>Light/Dark theme toggle with saved user preference and automatic system theme detection.</li>
  <li>Fully responsive navigation with a custom mobile drawer, smooth page transitions and touch-optimised interactions.</li>
  <li>Animated preloader with scroll restoration and seamless cross-page section navigation.</li>
  <li>Responsive hero video with autoplay support, custom smooth scrolling and active navigation highlighting.</li>
  <li>Interactive UI including a testimonials carousel, before/after comparison slider and animated FAQ section.</li>
  <li>Custom booking experience featuring an interactive calendar, appointment time selection and client-side validation.</li>
  <li>Animated treatment filtering with category transitions and responsive layouts.</li>
  <li>SEO-friendly setup using metadata, sitemap generation and robots configuration.</li>
  <li>Performance-focused architecture with reusable layouts, shared behaviours and component-based design.</li>
</ul>
